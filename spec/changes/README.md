# Specification change requests (architectural-change experiments)

Each file here specifies one requirement change used in the *architectural
change* experiment family. A change becomes part of the normative spec only for
the experiment that applies it; the main spec version is bumped when a change is
adopted permanently. Changes are applied identically to every language.

Written: `union-all.md` (CR-1), `decimal38.md` (CR-2), `refactor-plan-separation.md` (CR-3),
`kernels-i128.md` (CR-4, native kernels: assembly languages only), `kernel-refactor.md` (CR-5),
`expression-limits.md` (CR-6, resolves spec question SPEC-Q-002; ADR-0017)
(written when the corresponding experiment wave is scheduled, so that phase
agents are not influenced by them).
