# ADR-0006: Correlated subqueries are an optional capability

**Status:** Accepted (2026-10-10)

## Decision

Uncorrelated scalar/IN/EXISTS subqueries and derived tables are required in Phase 2; correlated subqueries are capability `sql.correlated_subquery` and must yield UNSUPPORTED if absent.

## Rationale and consequences

Keeps the mandatory scope comparable across languages while still allowing measurement of the harder feature. Not a scope reduction of the prompt, which lists 'Subqueries' without specifying correlation.
