# ADR-0003: Track A (controlled) library policy: standard library only

**Status:** Accepted (2026-10-10)

## Decision

In Track A every engine may use only the language's standard library (for Clojure: clojure.core + JDK; for SBCL: SBCL and its contribs incl. ASDF, sb-bsd-sockets, sb-posix, sb-thread, sb-concurrency), the language's standard build tool, and its standard unit-test facility. No third-party packages (no serde, no Jackson, no cheshire, no quicklisp).

## Rationale and consequences

Removes library availability as a confounder: every agent must implement JSON, CSV, HTTP, CRC-32, hashing, etc. itself. Track B lifts this restriction and records every library used in `ENGINE.json`. Consequence: some languages (Rust, Common Lisp, Java) need more code in Track A; that is a measured effect, not noise.
