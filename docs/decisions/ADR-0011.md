# ADR-0011: PQCF v1 uses a JSON footer

**Status:** Accepted (2026-10-10)

## Decision

PQCF stores metadata as a CRC-protected UTF-8 JSON footer and column data in simple fixed binary layouts (PLAIN/DICT/RLE).

## Rationale and consequences

Every engine must implement a JSON parser anyway (protocol), so a JSON footer minimizes format-specific parsing code while the binary chunk layouts still exercise low-level byte handling. Golden files are produced by an independent reference writer in `tools/validation/pqcf.py`.
