# ADR-0002: Toolchain versions

**Status:** Accepted (2026-10-10)

## Decision

Java: JDK 27 GA at `/usr/lib/jvm/jdk-27` (target Java 27 satisfied). Clojure 1.12.3 on JDK 27. Rust 1.96.0 stable. Go 1.27.1. CPython: newest stable installed via `uv python install` (see `tools/environment/versions.json`); system 3.12 is not used for the engine. Common Lisp: SBCL; Ubuntu's packaged SBCL 2.2.9 is old, so a current upstream SBCL binary is installed under `/opt/sbcl` when available and recorded. C: GCC 13.3 / Clang 18; NASM 2.16 and GNU as for x86-64; `aarch64-linux-gnu-gcc` 13.3 cross toolchain for AArch64.

## Rationale and consequences

Exact versions are captured automatically by `just doctor` into `tools/environment/versions.json` and into every experiment manifest.
