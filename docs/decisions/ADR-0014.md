# ADR-0014: Agent-run telemetry vs. orchestrator work

**Status:** Accepted (2026-10-10)

## Decision

Work done by the orchestrating session (spec, harness, generators, reports) is infrastructure and is not attributed to any language. Its own token usage is not machine-recorded (the interactive session does not expose it to itself) and is reported as unavailable.

## Rationale and consequences

Prevents infrastructure effort from contaminating per-language measurements.
