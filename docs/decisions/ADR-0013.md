# ADR-0013: One fresh agent session per (language, phase, attempt)

**Status:** Accepted (2026-10-10)

## Decision

Each phase of each language is a separate attempt with a fresh agent session whose workspace contains the language's accepted code from the previous phase. The prompt template is identical across languages except for the language name and toolchain section.

## Rationale and consequences

Gives per-feature telemetry, bounds context length, allows independent repetition, and matches the experimental unit 'language × feature × attempt'. Execution order of languages is randomized per wave with a recorded seed.
