# ADR-0005: No implicit string conversions; strict typing

**Status:** Accepted (2026-10-10)

## Decision

Comparisons and arithmetic between strings and numbers/dates are TYPE_ERROR. Integer division truncates; division by zero is always an error (also for floats); floats are always finite.

## Rationale and consequences

SQLite/MySQL-style permissive coercions are a large source of cross-implementation divergence. Strictness makes results deterministic and testable. Where this deviates from SQLite, the SQLite oracle cross-check is disabled for the affected tests and expected results are hand-written.
