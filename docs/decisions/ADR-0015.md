# ADR-0015: Benchmarks run natively on the host, not in Docker

**Status:** Accepted (2026-10-10)

## Decision

Benchmarks run as host processes pinned with `taskset` and limited with `prlimit`/cgroups where available. The Docker image is for reproducible builds and conformance, not for performance numbers (Docker Desktop runs a VM).

## Rationale and consequences

Avoids virtualization overhead being presented as native performance.
