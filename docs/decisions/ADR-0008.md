# ADR-0008: Agent platform adapter: Claude Code headless mode

**Status:** Accepted (2026-10-10)

## Decision

Agents are invoked as `claude -p --output-format stream-json --verbose --model <id>` inside the sandbox with an isolated `CLAUDE_CONFIG_DIR` containing only the OAuth credential (no user CLAUDE.md, memories, plugins or history). Telemetry (tokens incl. cache read/creation, cost, turns, API time vs wall time, tool calls and tool errors) is parsed from the stream.

## Rationale and consequences

This is the platform actually available. Token and cost figures come from the platform's own accounting; cost is list-price `total_cost_usd` as reported. Metrics the platform does not expose (e.g. reasoning-budget details, human time) are recorded as null or as 0 with justification (human interventions are 0 by construction in unattended runs).
