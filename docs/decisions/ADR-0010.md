# ADR-0010: ARM64 validation is emulated on this host

**Status:** Accepted (2026-10-10)

## Decision

The development host is x86-64 (AMD Ryzen 9 9950X3D, AVX2 + AVX-512). AArch64 kernels are built with the cross toolchain and tested under `qemu-aarch64-static` for **functional** correctness only. No AArch64 performance numbers are reported from emulation. Native AArch64 validation (M8) remains open until run on real hardware (e.g. an AWS Graviton instance or Apple Silicon); `just test-kernels` supports that directly.

## Rationale and consequences

Required by the prompt: never present emulated performance as native.
