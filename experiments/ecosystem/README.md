# Track B — ecosystem-optimized comparison

Track B starts from each language's accepted Track A Phase 4 engine and lifts the
standard-library-only rule: agents may use any libraries, compiler/runtime
settings, profilers and native interop (including `libpqkernels`). Every
library, flag and setting is recorded in `ENGINE.json` and the run manifest.
Track B results are reported separately from Track A (never one ranking).

Status: not yet run (requires Track A Phase 4 completion).
